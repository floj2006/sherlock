# Публичный запуск SHERLOCK

## Реализовано

- Единый локальный шрифт, адаптивные кейсы, просмотр фотографий и анимации с учётом reduced motion.
- Рейтинги мастеров из YCLIENTS, без подписи источника рядом с оценкой. Администраторы исключены из списка и онлайн-записи.
- Адрес и телефон на сайте, карта в тёмной палитре.
- Собственная форма `/book`, без модальной панели и внешнего календаря. Услуги, цены конкретного мастера, даты и слоты берутся из API.
- Проверка доступности и стоимости перед созданием визита. Успех показывается только после получения номера записи.
- Защита от повторной отправки, ограничение размера запроса, проверка origin и валидация контактов на сервере.
- Аналитика включается после согласия; `booking_complete` означает подтверждённую запись.
- Личный кабинет: вход через Яндекс ID, редактирование контактов, история записей с сайта и подстановка профиля в форму. При переходе к входу сохраняются выбранные услуги и мастер.

## Проверка интеграции

Партнёрский токен работает для филиала 1024543. Живые запросы списка мастеров, услуг, дат и сеансов успешны. `book_check` для реального свободного слота вернул HTTP 201. Реальная пробная запись не создавалась: создание, конфликты и повторная отправка проверены через локальный макет API.

Тексты отзывов остаются отдельной задачей доступа: существующий пользовательский токен получил HTTP 403. Это не мешает рейтингу и собственным методам онлайн-записи.

## Развёртывание

1. Выбрать сервер, домен и HTTPS; перенести серверные переменные окружения.
2. Подключить постоянный общий диск для `BOOKING_STATE_DIR`. Текущая защита от дублей требует файлового хранилища, общего для всех процессов. Для serverless понадобится общее хранилище или транзакционная БД; временный локальный диск не подходит.
3. Настроить общий rate limit на доверенном прокси, мониторинг и уведомления об ошибках.
4. Проверить реальный визит с согласованными контактами гостя, затем перенос и отмену.
5. Сверить статический каталог с ценами YCLIENTS, реквизиты оператора и точные часы работы. В самой форме используются актуальные цены API.
6. Пройти ручную проверку на телефонах и при слабом соединении.
7. Настроить Яндекс ID по [YANDEX_ID_SETUP.md](./YANDEX_ID_SETUP.md), указать рабочий HTTPS Redirect URI и проверить вход и выход. Разместить `ACCOUNT_DB_PATH` на постоянном локальном диске сервера вне `public` и включить резервное копирование. Текущий кабинет рассчитан на один сервер с SQLite; для нескольких серверов потребуется общая серверная БД.

Публичное развёртывание в рамках этой задачи не выполнялось. Для SMS-подтверждения или обязательной предоплаты потребуется соответствующее расширение формы; у текущего филиала SMS-подтверждение отключено, поддерживаются услуги с оплатой на месте.
